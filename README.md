# Step-by-Step Introduction to the ASP.NET Core MVC Framework

**The course is available online here: [https://stahe.github.io/en-aspnetcoremvc-sept-2026/](https://stahe.github.io/en-aspnetcoremvc-sept-2026/)**

## Overview

This course provides a step-by-step guide to building an MVC web application with **ASP.NET Core MVC** (.NET 10, C#). HTML pages are generated by the server using **Razor** views, without a browser-side JavaScript framework.

It follows the course *Step-by-Step Introduction to the NestJS Web Framework* (2026) and follows the exact same structure:

1. **28 short examples**, each focusing on a specific concept:
   - controllers, actions, and routing;
   - action model: parameter binding, conversion, and validation;
   - Razor views: templates, partial views, helpers, and Tag Helpers;
   - forms, validation, and the Post/Redirect/Get pattern (TempData);
   - internationalization (French/English);
   - data scopes: Singleton, Scoped, and Transient; cookies;
   - request lifecycle: middleware, filters, error pages;
   - authentication using a JWT token in a cookie, roles, CAPTCHA, and rate limiting;
   - layered architecture (Web / Business / DAO) with **Entity Framework Core** and **MySQL**.
2. **A comprehensive case study**, *RdvMedecins*: an appointment scheduling application for a medical practice, with three roles (administrator, doctors, patients). The course provides detailed explanations for each of its files.

Readers do not need any prior knowledge of ASP.NET Core: each example is commented line by line, and the course provides the exact URL to test for each one.

## Environment

- .NET SDK 10
- Visual Studio Code + C# Dev Kit extension
- MySQL (for example, with Laragon)
